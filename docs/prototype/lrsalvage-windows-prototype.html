Recover photos from Lightroom Classic previews

Windows quick start

Start the walkthrough · Practice with sample catalogs

1. Choose a Lightroom catalog

Pick the .lrcat file. If the matching preview folder lives somewhere else, choose it when prompted.

2. Scan for previews

If the originals were on an external drive, reconnect it and check again, or continue with previews.

3. Review photos

Switch between gallery and list views, and use Preview pane to inspect a photo as you browse. Group by folder to see photos by their original location. In an enlarged preview, use the arrow keys to move between photos and Esc to close it.

4. Choose a save folder

Keep the original folder structure inside the recovery folder or put all JPEGs together. Check the example paths and available space. Expand Customize file names if you want to add a prefix or suffix.

5. Open your JPEGs

Use Open folder on the receipt to see what was saved.
